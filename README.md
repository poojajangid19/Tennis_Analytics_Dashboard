# 🎾 ATP/WTA Tennis Analytics Dashboard

A comprehensive Tennis Analytics Dashboard built using Streamlit, Pandas, and Plotly to analyze ATP/WTA player rankings, competitors, tournaments, performance trends, and insights.

---

## 📌 Project Overview

This dashboard provides interactive analytics for professional tennis data, enabling users to:

- Explore competitors worldwide
- Analyze player rankings
- Compare players side-by-side
- View leaderboard standings
- Generate AI-powered insights
- Analyze competitions and tournaments

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/ATP-Tennis-Analytics-Dashboard.git
cd ATP-Tennis-Analytics-Dashboard
```

### Create Virtual Environment

```bash
python -m venv venv
```

Activate Environment:

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run app.py
```
